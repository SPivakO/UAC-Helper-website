# UA Helper - UAC Bulk Upload

Landing page для сервиса автоматизации загрузки креативов в Google UAC.

## Запуск локально

Просто открой `index.html` в браузере.

## Деплой

Проект настроен для деплоя на Netlify. Просто подключи Git репозиторий к Netlify.

## Настройка формы

Замени `LEAD_WEBHOOK_URL` в `index.html` на свой webhook URL для приема лидов.
